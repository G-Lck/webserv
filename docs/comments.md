# Comments Helpers


`@brief`
Short description

`@param`
name Description of parameter

`@return`
What it returns

`@throws`
ExceptionType When it's thrown

`@note`
Side note

`@warning`
Important warning

`@deprecated`
Don't use this anymore

`@todo`
Something to fix/add later

`@bug`
Known bug here

`@see`
OtherClass::otherMethod

`@since`
Version or date added

`@author`
Who wrote it

`@version`
Current version

`@date`
Date written

`@file`
File description (top of file)

`@class`
Class description

`@var`
Variable description

`@typedef`
Typedef description

`@enum`
Enum description

`@details`
Longer description after `@brief`

`@pre`
Precondition that must be true

`@post`
State after function runs
